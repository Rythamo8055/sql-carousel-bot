# 🎨 Carousel Design Styles

## Overview

4 distinct design styles for your Instagram carousels, each with unique aesthetics.

---

## Style 1: Minimal Elegant (Beige/Cream)

**File:** `morning-news-style1.html`

**Aesthetic:**
- Clean, minimalist design
- Beige/cream color palette
- Playfair Display serif font
- Subtle decorations
- Elegant typography

**Best for:** Professional, sophisticated content

**Colors:**
- Background: #f5f0eb (cream)
- Text: #1a1a1a (dark)
- Accent: #c4a882 (gold)

---

## Style 2: Bold Purple (Dark Mode)

**File:** `morning-news-style2.html`

**Aesthetic:**
- Bold, high-contrast design
- Purple/black color scheme
- Large numbers and arrows
- Modern microblog style
- Strong visual hierarchy

**Best for:** Tech content, bold statements

**Colors:**
- Background: #0a0a0a (black) / #7c3aed (purple)
- Text: #ffffff (white)
- Accent: #7c3aed (purple)

---

## Style 3: Blue Dark (Icons)

**File:** `morning-news-style3.html`

**Aesthetic:**
- Blue/dark theme
- Icon-based design
- Clean layouts
- Large numbers in background
- Modern, professional

**Best for:** Educational content, tutorials

**Colors:**
- Background: #3b82f6 (blue) / #0f172a (dark) / #f8fafc (white)
- Text: #ffffff / #0f172a
- Accent: #3b82f6 (blue)

---

## Style 4: Pink Wavy (Soft)

**File:** `morning-news-style4.html`

**Aesthetic:**
- Soft pink/cream palette
- Wavy line decorations
- Playfair Display font
- Gentle, calming feel
- Hand-drawn elements

**Best for:** Lifestyle, motivational content

**Colors:**
- Background: #f8b4b4 (pink) / #fef3e2 (cream)
- Text: #1a1a1a (dark)
- Accent: #dc2626 (red)

---

## How to Use

1. Open any style file in browser
2. Edit content in the HTML
3. Screenshot each slide as PNG
4. Upload to Instagram

---

## Customization

### Change Colors
Edit the CSS variables in each file:
```css
.bg-pink{background:#f8b4b4}  /* Change this */
.bg-cream{background:#fef3e2}  /* Change this */
```

### Change Fonts
Update the Google Fonts import:
```html
<link href="https://fonts.googleapis.com/css2?family=Your+Font:wght@400;700&display=swap" rel="stylesheet">
```

### Add Icons
Use emoji or import an icon library:
```html
<link href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined" rel="stylesheet">
<span class="material-symbols-outlined">code</span>
```

---

## Consistency Tips

1. Use the same style for each content type
2. Keep fonts consistent within a style
3. Maintain the same slide dimensions (1080x1350px)
4. Use the same username/logo placement
5. Keep the same number of slides per carousel
