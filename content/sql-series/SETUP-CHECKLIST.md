## ⚠️ Important Notes

### File Format
- Current files are **HTML** format
- Instagram requires **PNG/JPG images**
- Need to convert HTML to screenshots before posting

### Conversion Required
1. Open each HTML file in browser
2. Take screenshot (1080x1080 or 1080x1350)
3. Save as PNG
4. Upload to Instagram

### Color Consistency Check
All SQL Grid files use:
- Background: #d4cfc7 (beige)
- Text: #1a1a1a (black)

- Accent: #2563eb (blue)

## 📸 Instagram Post Settings

### Image Specifications
- **Size**: 1080x1080px (square) or 1080x1350px (portrait)
- **Format**: PNG or JPG
- **Quality**: High resolution
- **Slides**: Up to 10 per carousel

### Best Posting Times
- **11:00 AM** - Morning news
- **1:00 PM** - Problem solving
- **7:00 PM** - SQL series (prime time)
