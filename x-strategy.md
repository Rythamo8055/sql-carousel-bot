# 🐦 X (Twitter) Strategy Guide

## 🎯 X Overview

**What is X?** The town square for tech conversations

**Why use it?**
- Largest tech community
- Real-time conversations
- Thread format = deep dives
- Networking opportunities

---

## 📊 X Best Practices

### Content Format
| Type | Length | Frequency | Purpose |
|------|--------|-----------|---------|
| **Tweet** | 280 chars | 5-10x/day | Quick thoughts |
| **Thread** | 5-20 tweets | 2-3x/week | Deep dives |
| **Quote tweet** | With comment | 3-5x/day | Engagement |
| **Poll** | Question + options | 2x/week | Discussion |
| **Space** | Audio | 1x/week | Live engagement |

### Posting Times
| Day | Best Times | Why |
|-----|------------|-----|
| **Weekdays** | 8 AM, 12 PM, 5 PM | Work breaks |
| **Weekends** | 10 AM, 2 PM | Leisure time |

## 📝 X Content Templates

### Tweet Template
```
[Opinion/Observation]

[Supporting detail]

[Question/CTA]

Example:
"Just deployed a new API endpoint.

Response time: 12ms
Uptime: 99.99%
Cost: $0.003 per 1000 requests

This is what happens when you optimize from day 1."
```

### Thread Template
```
Tweet 1: Hook
"Here's [topic] in [number] steps: 🧵"

Tweet 2-19: Content
"1/ [First point]"
"2/ [Second point]"
...

Tweet 20: CTA
"That's it! Which one will you try first?

Like + Retweet to help others find this! 🙏"
```

### Quote Tweet Template
```
"[Your take on the original tweet]

[Additional value or perspective]

[Question to spark discussion]"
```

### Poll Template
```
[Question]

🔵 [Option 1]
🟢 [Option 2]
🟡 [Option 3]
🔴 [Option 4]

Votes in 24 hours! ⏰
```

## 💡 X Pro Tips

### Content Tips
1. **Hook in first line** - Stop the scroll
2. **Use line breaks** - Easy to read
3. **Add numbers** - Specificity wins
4. **Ask questions** - Encourage replies
5. **Be controversial** - Spark discussion

### Engagement Tips
1. **Reply to every comment** - Shows you care
2. **Quote tweet with value** - Add your take
3. **Join Twitter Spaces** - Live engagement
4. **Follow niche accounts** - Build network
5. **Be consistent** - Show up daily

### Growth Tips
1. **Cross-promote** from Instagram
2. **Join conversations** in your niche
3. **Create threads** - They get more reach
4. **Use hashtags** - #API #WebDev #Tech
5. **Be patient** - Growth takes time

## 🐦 X + Instagram Synergy

### Cross-Promotion Strategy
```
Instagram → X:
"Just dropped a carousel on [topic]!

TL;DR:
1. [Point 1]
2. [Point 2]
3. [Point 3]

Full carousel in bio 👆"

X → Instagram:
"Made a thread about this topic!

8 tweets breaking down:
- [Topic 1]
- [Topic 2]
- [Topic 3]

Check it out! Link in bio 👆"
```

### Content Repurposing
```
Instagram Carousel → X:
Slide 1 → Hook tweet
Slide 2-7 → Thread
Slide 8 → CTA tweet

YouTube Video → X:
Main points → Thread
Behind the scenes → Tweet
Call to action → Poll
```
